# Risk flag datasets

Manually scraped datasets for risk flags designed for multi-label binary classification.

### reddit_safe.csv
* contains only ‘safe’ label (used to sample the 'safe' label for other 4 datasets)

```
label
safe    19485
```

  
### reddit_selfharm.csv
* contains labels ‘selfharm’ and ‘safe’

```
label
safe        2000

```


### reddit_grief.csv
